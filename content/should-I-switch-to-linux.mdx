# Should I Switch to Linux?

Some people may think that I already use Linux on my laptop. However, that is not the case.

I have been using macOS since 2013. Before that, I used Windows, but Windows 8 with all its tiles was not for me. In my opinion, Microsoft was moving in the wrong direction, so I switched to macOS.

Since then, I have been a happy macOS user. I am also quite invested in the Apple ecosystem, which makes switching more difficult.

Lately, I have been reading more and more articles suggesting that this could finally be “the year of Linux on the desktop.” But people have been saying that for years, so I am still not completely convinced.

I already use Linux in my server environment, and I absolutely love it there. It is stable, reliable, and gives me a lot of control. For servers, Linux is my first choice.

I have experimented with Linux on desktops and laptops before, but only for a short time and that was many, many years ago. Unfortunately, it was not a successful experience. That is one of the reasons why I still have doubts about using Linux as my daily desktop operating system.

But Linux has improved a lot since then. Could it now offer the same comfortable experience as macOS for my daily work?

So, I have a question for my network:

Should I start experimenting with Linux on a laptop again? If so, which Linux distribution would you recommend: Ubuntu or Fedora? Or should I simply stay with macOS?

I would love to hear about your experiences.
