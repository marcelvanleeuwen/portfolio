Today I spent some time working on my website again.

I added more articles to the [Knowledge wiki](/knowledge). These articles come from my notes on GitHub. They cover things I use in my homelab, like Kubernetes, Talos, FluxCD, and Argo CD. It is nice to have these notes together on my own website, where they are easier to find and read.

The wiki now also shows the last update date for each article. I added pages with 10 articles per page, using the same page buttons as the blog. This keeps the list a little easier to browse as more articles are added.

I also made some security fixes and a few small changes around the website. Some changes are easy to see. Others are small things in the background, but they still help keep the website in good shape.

One small change in the blog is the category name. I changed **Personal** to **Life**, because I think that name fits those posts better.

There is always something to improve. Today was about adding useful notes, fixing a few things, and making the website a little better, one step at a time.
