# Dear MINISFORUM,

I’ve been a big fan of MINISFORUM ever since I started using the MINISFORUM MS-01 in my Proxmox VE cluster.

The MS-01 has been a great platform for virtualization and homelab projects, especially because of the 2x SFP+ 10Gb ports. High-speed networking makes a huge difference when working with virtual machines, containers, and storage traffic.

Now MINISFORUM is introducing the new MINISFORUM S7 all-flash NVMe NAS, and I’m really excited about it. What immediately caught my attention is that it also includes 2x SFP+ 10Gb connections. This opens the door for very fast shared NVMe storage in combination with my Proxmox cluster.

I’m seriously considering moving toward shared all-flash NVMe storage for better VM performance, faster migrations, and a more powerful homelab setup overall.

It’s great to see compact hardware becoming this powerful and network-focused.
